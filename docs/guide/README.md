# pstack 가이드

pstack은 에이전트를 일일이 마이크로매니징하는 것을 멈출 때 가장 잘 작동합니다. 원하는 것이 무엇이고 작업이 끝났음을 어떻게 확인할지만 설명하면 됩니다. `/poteto-mode`가 플레이북을 고르고, 각 단계에서 필요할 때 다른 스킬들을 실행하며, 그 증거를 보여줍니다. 이 가이드는 현실적인 프롬프트 예시를 통해 그러한 습관을 기르는 법을 안내합니다.

이 가이드에서 다룰 내용은 다음과 같습니다:

1. [pstack 설정하기](./01-setup.md). 플러그인을 설치하고 사용할 모델을 선택합니다.
2. [`/poteto-mode`를 통해 작업 라우팅하기](./02-poteto-mode.md). 목표를 부여하고 알맞은 플레이북을 고르는 과정을 살펴봅니다.
3. [코드 이해하기](./03-understand.md). 무언가를 편집하기 전에 읽기 전용 조사를 수행하고 `/how`, `/why`, `/teach`, `/recall`을 활용합니다.
4. [변경 사항 설계하기](./04-design.md). 코드가 특정 형태로 굳어지기 전에 `/architect`, `/arena`, `/swarm`, `/interrogate`, 프로토타입 및 계획을 활용합니다.
5. [변경 사항 구현 및 정리하기](./05-build-and-clean.md). 빌드 플레이북들과 `/tdd`, `/unslop`, `/no-comments`를 다룹니다.
6. [검증 및 배포하기](./06-verify-and-ship.md). 실제 앱에서 동작을 증명하고, 테스트가 닿기 어려운 영역을 정형 검증하며, `/benchmark-checklist`로 수치를 검증한 뒤 집중된 PR을 열어 머지까지 이끕니다.
7. [잠든 사이에 작업 실행하기](./07-overnight.md). 루프 실행 전 신뢰 확보, 야간 자율 실행 계약(overnight contract), 감사 가능한 의사결정 로그, 그리고 단일 에이전트 규모를 넘어 확장하는 프로젝트(Projects)와 자동화(automations)를 다룹니다.
8. [원칙 이름으로 방향 조율하기](./08-principles.md). 과업 도중 에이전트의 방향을 바로잡아 주는 24개의 원칙 이름을 알아봅니다.
9. [나만의 것으로 만들기](./09-make-it-yours.md). 나만의 모드 만들기, 반복되는 실수를 잡는 `/correct`, 그리고 스킬 변경 사항을 테스트하는 방법을 다룹니다.
10. [레시피 및 흔한 함정](./10-recipes-and-pitfalls.md). 바로 복사해서 쓸 수 있는 프롬프트와 피해야 할 실수들을 정리합니다.

처음 읽을 때는 순서대로 읽어보세요. 그 이후에는 각 페이지를 독립적으로 참고할 수 있습니다.

막히거나 어떤 스킬이 맞는지 잘 모르겠다면 질문과 함께 [`/poteto-help`](../../skills/poteto-help/SKILL.md)를 입력하세요:

```text
/poteto-help which skill should i use to review this branch?
```

질문에 답하고, 바로 보낼 수 있는 프롬프트를 건네주며, 답변의 출처가 된 스킬이나 가이드 페이지 링크를 알려줍니다. pstack 실행에는 실제 토큰이 소비되므로 바로 작업을 시작하지는 않으며, 준비가 되었을 때 프롬프트를 직접 보내면 됩니다. 이 스킬은 직접 입력할 때만 실행됩니다.

## 딱 하나만 기억해야 한다면

자신의 말로 에이전트에게 목표와 완료 확인 방법을 알려주세요:

```text
/poteto-mode the export writes duplicate rows when a retry lands mid-run. repro first, then fix and verify.
```

플레이북 이름을 대거나 스킬 목록을 나열할 필요가 없습니다. "repro first(먼저 재현할 것)"와 확인 가능한 결과만 있으면 `/poteto-mode`가 라우팅하는 데 필요한 신호로 충분합니다. Bug fix 플레이북을 매칭하고, 할 일 목록에 단계들을 복사해 넣은 뒤, 각 단계가 실행될 때 알맞은 스킬들을 호출합니다.

다음: [pstack 설정하기](./01-setup.md).
