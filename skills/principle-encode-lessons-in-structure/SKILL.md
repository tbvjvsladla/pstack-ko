# 교훈을 구조에 각인하라 (Encode Lessons in Structure)

교훈에 판단력이 필요하여 구조적으로 인코딩할 수 없다면, 지침을 더 눈에 띄게 배치하고 실패 모드의 구체적인 예시를 추가하세요.

**따름정리(Corollary):** 해결책이 구조적인 것이라면, 오직 구조적 해결책만 사용하세요. 지침 문구는 증상일 뿐입니다.
