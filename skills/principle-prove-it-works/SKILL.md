# 작동함을 증명하라 (Prove It Works)

기능을 직접 실행하고, 실제 값을 읽고, diff를 검사하는 등 실제 대상을 직접 확인하여 모든 산출물을 검증하세요. 대리 지표(파일 mtime, 자체 보고, 캐시된 출력, "컴파일이 된다")는 인정되지 않습니다. 검증이 실패하면 시스템을 의심하기 전에 관측 방법부터 의심하세요.

가능할 때는 검증을 스크립트로 작성하세요. 비교를 재실행하는 결정론적 스크립트가 한 번 눈으로 확인하는 것보다 낫습니다. 출력은 사람이 볼 수 있는 곳에 두고, 나중에 감사(audit) 추적이 필요할 때만 커밋하세요.
