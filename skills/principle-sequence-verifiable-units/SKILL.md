# 검증 가능한 단위로 작업 순서를 배치하라 (Sequence work into verifiable units)

작업을 각각 확인할 수 있는 상태로 끝나는 작은 단위들로 배치하고, 현재 단위가 통과(green)하기 전에는 다음으로 넘어가지 마세요.

일괄 수정(sweep), 마이그레이션, 또는 유사한 편집의 연속 작업에서 각 단위는 하나의 괄호(bracket)입니다: 정상으로 확인된 상태, 단일 변경, 검증 실행, 진행. 도구가 편집을 수행할 때도 단위별 검증을 실행하세요.

작업을 증명하는 순서대로 전달하세요: 실패하는 테스트를 먼저 두고 그다음 수정, 형태 변경 전에 뺄셈 먼저, 처치 적용 전에 베이스라인 먼저. 각 커밋은 그 자체로 온전히 성립해야 합니다.
