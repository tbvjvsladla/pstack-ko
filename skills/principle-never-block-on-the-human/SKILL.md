# 사람 때문에 블로킹되지 마라 (Never Block on the Human)

사람은 비동기적으로 감독합니다. 에이전트는 블로킹되지 않고 계속 움직여야 합니다. 합리적인 결정을 내리고 작업을 진행한 뒤, 사람이 사후에 방향을 교정할 수 있게 하세요. 코드 변경은 되돌릴 수 있고 리뷰할 수 있으므로, 잘못된 결정을 내리는 비용이 대기하며 멈춰 서 있는 비용보다 대개 더 저렴합니다.

- 먼저 진행하고 결과를 제시하세요. 작업을 수행하고 결과를 보여주세요. "X를 할까요?"라고 묻지 마세요. X를 수행하고 왜 그렇게 했는지 설명하세요.
- 시스템을 자가 치유(self-healing) 가능하게 만드세요. 문제를 발견하면 기록해 두고 다음 라운드에서 수정하세요.
- 되돌릴 수 없는 비가역적 행동(강제 푸시, 프로덕션 데이터 삭제, 외부 메시지 발송)은 여전히 사전 확인이 필요합니다.
- 되돌릴 수 있는 가역적 행동(코드 작성, 노트 편집, 태스크 분할)은 멈추지 말고 진행해야 합니다.
- 제품의 방향성은 사람에게서 나오지만, 실행 과정이 블로킹되어서는 안 됩니다.
