# 탐색자 프롬프트 템플릿 (Explorer Prompt Template)

이 템플릿을 바탕으로 각 탐색자(explorer) 서브에이전트의 프롬프트를 구성하세요. 플레이스홀더를 실제 값으로 채워 넣습니다.

---

다른 탐색자들이 동일한 서브시스템의 서로 다른 단면들을 병렬로 조사하고 있습니다. 모든 것을 다 다루려 하지 마세요. 당신에게 할당된 관점(angle)에 집중하여 깊이 파고드세요.

## 질문 (Question)

> {QUESTION}

## 당신의 탐색 관점 (Your Exploration Angle)

{EXPLORATION_ANGLE}

## 출력 (Output)

### Components Found
핵심 타입, 서비스, 클래스, 추상화 목록입니다. 각 항목마다 이름, 파일 경로, 그리고 무슨 일을 하는지 설명하는 한 문장을 적으세요.

### Flow
단계별 실행 흐름입니다. 각 단계마다 어떤 함수/메서드가 실행되는지, 어느 파일에 있는지, 무슨 일을 하는지, 다음에 무엇을 호출하는지 적으세요. 단계 사이를 흐르는 데이터도 포함하세요.

### Files Read
설명자(explainer)가 참조할 수 있도록 탐색 과정에서 읽은 모든 파일을 나열하세요.

### Boundaries
이 서브시스템이 코드베이스의 다른 부분과 연결되는 지점입니다. 입력과 출력을 명시하세요.

### Non-Obvious Things
놀라운 점, 역사적 동기가 있는 부분, 또는 실수하기 쉬운 부분입니다. 한 방식으로 동작할 것처럼 보이지만 실제로는 다르게 동작하는 것들을 적으세요.

### Open Questions
완전히 추적하거나 이해하지 못한 부분입니다. 빈틈(gaps)에 대해 정직하게 적으세요.
