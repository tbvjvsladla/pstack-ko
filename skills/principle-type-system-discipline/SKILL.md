# 타입 시스템 규율 (Type System Discipline)

컴파일러가 불가능한 상태, 잘못 짝지어진 원시 값, 처리되지 않은 변형(variant)을 거부하도록 만드세요.

- **의미를 가진 원시 타입에 브랜드(brand)를 부여하세요.** 두 인자가 동일한 원시 타입을 공유하지만 의미가 다르다면 각각에 고유한 타입을 부여하세요. 생성 시점에 한 번만 유효성을 검사하세요.
- **외부 데이터는 파싱되기 전까지 타입이 없는 것입니다.** JSON, RPC 페이로드, CLI 인자, 설정, 환경 변수, 데이터베이스 행(row)은 경계에서 타입이 지정된 모델을 반환하는 파싱 함수를 거쳐야 합니다.
- **권위 있는(authoritative) 스키마로부터 타입을 파생시키세요.** 스키마 파일이 데이터 형태(shape)의 소유권을 가지고 있다면, 별도의 타입을 수작업으로 중복 정의하지 말고 해당 스키마로부터 파생시키세요.

TypeScript 문법에 관해서는 **typescript-best-practices** 스킬을 참고하세요.
