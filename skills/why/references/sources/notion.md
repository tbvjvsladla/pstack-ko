# Notion 문서 (Notion Docs)

## 이 소스에 담긴 내용 (What this source contains)

- PRD (제품 요구사항 문서, product requirement documents)
- 기술 스펙 및 RFC
- 아키텍처 결정 기록 (ADR)
- 설계 리뷰 회의록
- 도메인 맥락이 담긴 팀 페이지
- 인시던트 포스트모템
- 방어적 코드를 설명해 줄 수 있는 런북(Runbooks)
- 우선순위를 설정하는 전략 문서

Notion은 코드가 되기 전에 "왜(why)"가 장문의 형태로 먼저 기록되는 곳입니다. 중요한 기능에는 대개 관련 문서가 존재합니다.

## 검색 방법 (How to search it)

Notion MCP를 사용하세요.

1. **`notion-search`로 키워드 검색하기.** 다음 항목들을 시도해 보세요:
   - 기능 이름
   - 대상 코드의 핵심 심볼 / 클래스 이름
   - 작성자 핸들 (설계 문서는 대개 코드가 머지되기 전에 작성됩니다)
   - 에러 문자열 또는 사용자에게 노출되는 용어
   - 코드가 배포된 시점을 알고 있다면 시간 범위가 지정된 쿼리
2. **`notion-fetch`로 후보 페이지 가져오기.** 미리보기만 보지 말고 전체 내용을 읽으세요. 설계 근거는 문서 중간에 묻혀 있는 경우가 많습니다.
3. **백링크와 하위 페이지를 따라가기.** 설계 문서에는 대개 검토된 대안들(alternatives considered), 부록, 또는 구현 노트를 담은 하위 페이지가 있습니다.
4. **관련 데이터베이스 확인하기.** `notion-query-data-sources`와 `notion-query-meeting-notes`를 사용하면 해당 결정을 논의했던 회의록을 발굴할 수 있습니다.
5. **작성자별 공간 검색하기.** PR 작성자가 개인 노트북을 가지고 있다면(일부 회사에서는 흔함), 코드 작성에 앞선 탐색적 사고 과정이 담겨 있을 수 있습니다.

## 좋은 근거의 모습 (What good evidence looks like here)

- 대상 코드의 목적과 일치하는 "문제 정의(Problem statement)" 또는 "동기(Motivation)" 섹션이 있는 PRD
- "검토된 대안(Alternatives considered)" 또는 "기각된 접근법(Rejected approaches)" 섹션
- 특정 인시던트에 대한 수정 사항으로 대상 코드를 지목하는 포스트모템
- "Y 때문에 X로 결정했다"고 기록되어 있으며 PR과 동일한 작성자/날짜 범위로 연결되는 회의록
- 충실하게 작성된 ADR 템플릿 (상태, 맥락, 결정, 결과)

## 흔한 함정 (Common pitfalls)

- **오래된 문서 (Outdated docs).** 스펙은 대개 구현 전에 작성되고 이후 업데이트되지 않습니다. 문서가 변경되기 전의 계획을 설명하고 있을 수 있습니다. 실제 PR과 교차 확인하세요.
- **문서와 현실의 괴리 (Doc vs. reality drift).** 스펙에는 "X를 할 것이다"라고 적혀 있지만 실제 코드는 Y를 수행할 수 있습니다. 이러한 불일치를 표시하세요. 통합자가 이 모순을 수면 위로 드러낼 것입니다.
- **상투적인 템플릿 (Boilerplate templates).** 일부 조직은 "Why" 섹션을 필수로 요구하지만 알맹이 없는 미사여구로 채워지곤 합니다. 구체성이 있는지 확인하세요.
- **링크되지 않은 문서 (Unlinked docs).** 가장 관련성 높은 문서가 어디에도 링크되어 있지 않을 수 있습니다. 폭넓은 키워드 검색이 도움이 됩니다.
- **여러 개의 초안 (Multiple drafts).** 하나의 주제에 대해 여러 문서가 있다면 최종 확정되었거나 가장 최근에 업데이트된 문서를 찾으세요. 날짜를 확인하세요.
- **접근 제한된 페이지 (Access-restricted pages).** 페이지에 접근할 수 없다면 공백(gap)으로 기록하세요.

## 반환할 내용 (What to return)

관련된 각 문서에 대해:
- 제목 및 URL
- 작성자 및 최종 수정일
- 페이지/섹션 위치가 포함된 동기 텍스트 (원문 인용)
- 관련된 링크된 페이지들 (통합자가 인용할 수 있도록)
- 문서가 최종본(finalized)인지 초안(draft)인지 여부
