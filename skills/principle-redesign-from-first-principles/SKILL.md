# 제1원칙에서 재설계하라 (Redesign From First Principles)

변경 사항을 통합할 때 기존 설계 위에 덧대어 붙이지(bolt on) 마세요. 마치 그 요구사항이 처음부터 기반 가정(foundational assumption)이었던 것처럼 재설계하세요.

- 영향을 받는 모든 파일을 읽고 현재 설계를 이해하세요
- 자문하세요: "이 새로운 요구사항을 안고 처음부터 백지상태에서 작성한다면 무엇을 만들까?"
- 타입, 문서, 예제, 설계 근거(rationale) 섹션 등 모든 참조에 변경 사항을 전파하세요
- 전체 재설계를 구상한 다음, 점진적으로 전달(deliver)하세요

이것은 기존 설계에 변경 사항을 통합할 때 옵션 가치(option value)를 보존하는 방법입니다.
