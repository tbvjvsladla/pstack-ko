# Ketchup video

[`/ketchup`](../ketchup/SKILL.md)을 따르되, 요약문과 시각 자료 대신 자막이 달린 짧은 비디오로 그동안 일어난 일을 보여줍니다. 시간 범위는 이전의 다른 `/ketchup` 호출 시점이 아니라, 사용자가 `/ketchup-video` 직전에 작성한 마지막 메시지부터 시작합니다. 저장소 외부에 비디오를 작성하고 렌더링하는 작업만 유일하게 읽기 전용(read-only) 규칙의 예외로 허용됩니다. 응답 구성은 ketchup의 첫 문장, 인라인으로 삽입된 비디오, 스스로 처리할 수 있는 남은 작업을 알리는 한 줄, 그리고 액션 아이템 목록입니다. 비디오에서 결정 사안의 선택지들을 보여줄 때는 비디오가 붙인 이름 그대로 각 선택지를 부르세요. 만약 비디오 렌더링에 실패하면 한 줄로 그 사실을 알리고 결정 사안(calls)들만 제시하세요.

## 슬라이드 (Slides)

채팅에 적힌 산문 설명이 아니라 실제 작업이 만들어낸 스크린샷, 녹화본, diff, 데이터를 사용하세요. 그림을 그리기 전에 사용자가 최종적으로 기억해야 할 한 문장과 슬라이드별 핵심 한 줄을 먼저 적어 보세요. 사용자가 아는 바를 바꾸지 못하는 슬라이드는 모두 버리세요. 슬라이드는 최대 10장까지만 사용하며, 적을수록 좋습니다. 사전 메모로 작성한 두 노트는 응답에 포함하지 않습니다.

각 슬라이드는 단 하나의 요점만 전달합니다. 슬라이드마다 무관한 새 그림으로 화면을 전환하지 말고, 하나의 기본 그림 위에 슬라이드를 구축하여 슬라이드가 넘어갈 때마다 그림이 변화하게 만드세요. 색상이나 도형은 모든 슬라이드에서 동일한 의미를 가져야 합니다. 시스템의 동작 방식, 각 PR의 상태가 표시된 PR 스택, 수정 전후 비교, 나란히 놓인 선택지들처럼 작업 내용을 그림으로 보여주세요. 화살표, 하이라이트, 움직임(motion)을 사용해 무엇이 바뀌었는지 가리키세요. 슬라이드는 절대 불릿 목록, 상태 목록, 표, 또는 서로 아무런 연결선도 없는 상자들의 나열이어서는 안 됩니다.

텍스트는 최소한으로 유지하세요. 각 라벨은 그것이 가리키는 대상 위에 직접 배치하고, "Tests: pass" 같은 태그가 아니라 사람이 실제로 말할 법한 평이한 단어로 적으세요. 그림이 이미 보여주는 내용을 캡션으로 중복 설명하지 말고, 슬라이드 간에든 슬라이드 아래의 텍스트에서든 동일한 사실을 두 번 말하지 마세요.

사용자가 요청한 각 항목이 어떻게 되었는지, 그리고 완료되었는지, 아직 실행 중인지, 실패했는지, 아니면 확인되지 않았는지 보여주세요. 아직 사용자의 조치를 기다리고 있는 항목을 완료된 것으로 표시하지 마세요. 진행 과정에서 발견해 수정한 버그가 있다면 보여주세요. 눈에 보이는 변경사항인데 스크린샷이 없다면 해당 슬라이드에 그 사실을 밝히고 화면에서 무엇이 바뀌었는지 적으세요. 오직 당신이 실제로 확보한 사실만을 바탕으로 그리세요. 수치를 지어내지 말고, 직접 캡처하지 않은 화면을 상상해서 그리지 마세요.

## 자막 (Subtitles)

각 슬라이드마다 그 슬라이드가 보여주는 내용만을 바탕으로, 사용자에게 직접 말하듯 핵심 요점을 전달하는 약 10단어 내외의 짧은 자막 한 줄을 달아주세요. 그림 안의 라벨을 그대로 소리 내어 읽지 말고 그림이 무엇을 의미하는지 말하세요. 자막은 슬라이드 아래쪽의 별도 띠(strip) 영역에 배치하며, 이 영역은 모든 슬라이드에서 높이가 같고 자막 외에는 비어 있어야 슬라이드 본문을 절대 가리지 않습니다. 글자 크기는 작게 설정하되 채팅창 크기로 재생할 때도 충분히 읽을 수 있어야 합니다.

## 렌더링 (Render)

슬라이드 간 전환 모션이 있는 무음 가로형(landscape) 비디오(예: mp4) 하나를 렌더링합니다. 모든 프레임은 자막 띠 바로 위에 슬라이드 자체가 여백 없이(edge to edge) 꽉 차게 배치된 형태여야 합니다. 화면을 녹화하지 말고 슬라이드로부터 직접 프레임을 생성하며, 각 자막을 해당 슬라이드의 프레임에 직접 구워 넣어(burn in) 슬라이드가 유지되는 시간(hold) 내내 화면에 머물게 하세요. 유지 시간(hold)이란 슬라이드로 들어오거나 나가는 전환 모션 시간을 제외하고 슬라이드가 온전히 화면에 떠 있는 시간입니다. 각 슬라이드는 새로 추가된 단어들을 읽기에 충분한 시간(최소 3단어당 1초 이상) 동안 유지하세요. 슬라이드가 추가하는 단어란 해당 슬라이드의 자막과, 변경된 라벨을 포함해 직전 슬라이드에는 없었던 모든 단어입니다. 첫 번째 슬라이드는 자신의 모든 단어를 새로 추가합니다. 스크린샷 이미지 내부에 원래 들어 있는 단어들은 세지 않습니다.

비디오를 응답에 삽입하기 전에 렌더링된 파일을 직접 점검하세요. 각 슬라이드에서 프레임을 하나씩 뽑아 채팅창 크기로 보면서 자막이 잘 읽히는지, 가리는 부분은 없는지 확인하세요. 페이드(fade) 효과의 희미한 끝부분까지 정지 화면으로 잘못 계산하는 정지 프레임 감지기(still-frame detector)를 쓰지 말고, 파일의 프레임들을 슬라이드와 직접 대조하여 각 슬라이드의 유지 시간을 측정하세요. 측정된 유지 시간 대비 각 슬라이드가 추가하는 단어 수를 계산하세요. 그 시간 안에 다 읽을 수 없는 슬라이드가 있다면 수정한 뒤 다시 렌더링하고 다시 점검하세요.
