# 컨텍스트 윈도우를 사수하라 (Guard the Context Window)

**이유:** 컨텍스트 오버플로는 추론 품질을 떨어뜨리고, 압축 아티팩트(손실)를 유발하며, 작업 진행을 멈추게 만듭니다.

**패턴:**
- **단계의 크기를 조절하고 범위를 제한하세요.** 단계당 파일 수를 제한하고, 턴 예산을 설정하며, 메커니즘 자체의 비용을 계산에 넣으세요.
